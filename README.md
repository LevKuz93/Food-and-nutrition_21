# Food-and-nutrition_21

# Food and Nutrition: Smart Diet Assistant

> Консольное ML-приложение, которое анализирует список ингредиентов, прогнозирует гастрономический рейтинг будущего блюда, рассчитывает его пищевую ценность и подбирает похожие рецепты с портала Epicurious.

---

## Обзор проекта

Проект решает проблему скудного городского рациона и неумения комбинировать продукты. На основе анализа исторических данных рецептов приложение помогает пользователю понять, насколько удачным и полезным получится блюдо из имеющихся в холодильнике продуктов, а также выводит подробный нутриентный профиль в процентах от суточной нормы.

---

##  Архитектура проекта

Проект разбит на три логических этапа и состоит из следующих ключевых файлов:

* **`recipes.ipynb` (Исследование)** — Jupyter Notebook, в котором проводится предобработка датасета Epicurious, обучение/валидация моделей регрессии и классификации (Scikit-Learn), подбор оптимальных бизнес-метрик, а также интеграция с Nutrition API для сбора данных о пищевой ценности.
* **`recipes.py` (Разработка)** — готовый Python-модуль, инкапсулирующий отработанную в ноутбуке бизнес-логику в кастомные классы и методы.
* **`nutritionist.py` (Основная программа)** — финальный CLI Command Line Interface — «Интерфейс командной строки»
  -скрипт автоматизации, принимающий на вход список ингредиентов и выводящий комплексный отчет для пользователя.

---

##  Основной функционал

Программа выполняет три ключевые задачи:
1. **Прогноз качества:** Определяет категорию рейтинга потенциального блюда (`bad`, `so-so`, `great`).
2. **Nutrition Facts:** Рассчитывает суточную норму (%) макро- и микронутриентов для каждого ингредиента.
3. **Рекомендация:** Находит ТОП-3 наиболее подходящих рецепта с прямыми URL-ссылками.

Бонусная фича: Генератор сбалансированного дневного меню (Завтрак/Обед/Ужин), максимизирующий гастрономический рейтинг и строго покрывающий суточную норму нутриентов без ее превышения.

---

##  Полученные навыки

* **Сквозная ML-разработка (End-to-End):** Опыт прохождения всех стадий создания Data Science продукта — от сырых данных в Jupyter до работающего консольного приложения.
* **Интеграция с внешними API:** Практика сбора, очистки и трансформации нутриентных данных из сторонних API-интерфейсов в структурированные DataFrames и CSV-матрицы.
* **Объектно-ориентированное проектирование (ООП):** Умение переносить прототипы исследований из хаотичной среды блокнотов в чистый, модульный и масштабируемый код на Python.
